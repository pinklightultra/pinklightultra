## Featured

1. **[doc-skills-library](https://github.com/pinklightultra/doc-skills-library)** — Twenty-one Claude Code skills for a documentation corpus: audit it, review a draft before it goes to a customer, and catch the specific ways that work goes wrong. Each skill is a `SKILL.md` prompt.

2. **[doc-type-classifier](https://github.com/pinklightultra/doc-type-classifier)** — Tells documentation types apart by structure. HTML in, one of thirteen types out, with the reason. No model and no network.

3. **[kbkit](https://github.com/pinklightultra/kbkit)** — Standard-library Python helpers for knowledge-base tooling: Atlassian Document Format, HTML article text, paged REST APIs, and MCP tool-result files.

4. **[GraphicNovelSans](https://github.com/pinklightultra/GraphicNovelSans)** — Turns hand-lettered drawings into a four-style TrueType / WOFF2 family. The reference face, BLUE175 Hand, is traced from the graphic novel *BLUE175*.

5. **[muthr-terminal-theme-kit](https://github.com/pinklightultra/muthr-terminal-theme-kit)** — Twenty-nine CRT themes for Windows Terminal, with HLSL pixel shaders, an on-screen display for the shader sliders, and a typed boot banner.

6. **[Portfolio](https://justinsevern.com)** — Writing samples (procedures, reference, style, release notes) and the longer account of the documentation systems.
